# OfxSpeak

OfxSpeak is a desktop TeamSpeak 3 client for Windows with full Hebrew support, made for our group.
It connects to ordinary TeamSpeak 3 servers for voice and chat, and talks to the Ofek bot for music and ARAM augments.

This repository only hosts the Windows downloads. There is no source code here.

## Install

1. Open the [latest release](https://github.com/tkss15/ofxspeak-releases/releases/tag/desktop-test-1) and download `ts3-desktop-win-x64-59d753465bca.zip`.
2. Unzip it to a folder you will keep, such as `%LOCALAPPDATA%\Programs\OfxSpeak`.
3. Run `ts3-desktop.exe`.
4. The app is not code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info**, then **Run anyway**.

Needs Windows 11 x64. `RUN.md` in the zip explains connecting, voice, bookmarks and shortcuts.

To update, close the app, unzip the new release into the same folder and replace the files. Your identity and settings are kept separately in your Windows profile.
